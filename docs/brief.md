# Brief (agreed in brainstorming)

**Goal:** never miss student effort.

**Teacher:** uploads competencies, instructions and rubric per posted activity. Clicks Pre-score (AI) or scores manually. Approves all grades and extra points.
**Student:** sees required submissions, status (checked or not) and score. Submits via phone camera, dedicated scanner-style camera, or essay text. Can file effort claims for extra points.
**Host:** the teacher's PC with a Claude or Codex subscription, logged in. The server shells out to the CLI. Students connect via LAN, Cloudflare Tunnel or Tailscale.

**Grading:** DepEd Order 015, s. 2026. Three terms. WW 20 / PT 50 / EX 30 (EPP/TLE/MAPEH 20/60/20). IG 70 transmutes to 75 in SY 2026-27 (zero-based later), so the transmutation table is swappable data. Formative work is not counted. Extra points are teacher-approved additions to a PT item.

**Open items:** verify component percentage method against the official E-Class Record; confirm the extra-points policy; pick stack (proposed: Node/TypeScript + SQLite); student login (proposed: ID + PIN).
