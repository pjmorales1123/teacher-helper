# Accomplishment Report: how to write it

## What it is and when a teacher uses it
A dated list of what the teacher actually did in a period (week, month, quarter). It goes to the School Head with the proof attached. DO 006 s.2025 names the report type but gives no layout.

## Page setup
A4, portrait, Arial 12, 1-inch margins. House style, not Times New Roman 2.5 cm (research open question 4, default accepted). A long table continues on the next page with the header row repeated.

## Parts, in order
| Part | What goes in it | Who supplies it | Length and style |
|---|---|---|---|
| ACCOMPLISHMENT REPORT | Fixed title | Code | One line, capitals |
| For the Period | Start and end date | Teacher | One line |
| Name of Personnel | Teacher name | Profile | One line |
| Division | Division name | Profile/letterhead | One line |
| Bureau/Office | School name | Profile/letterhead | One line |
| Designation | Teacher position | Profile | One line |
| Summary | What the period was about | AI, from the teacher's rows | 2 to 3 sentences |
| Table column: Date | Day or date range | Teacher | One date per row |
| Table column: Actual Accomplishment/Output | What was done and what came out of it | Teacher facts, AI wording | 1 to 2 sentences per row |
| Table column: Evidence (optional) | File or photo name | Teacher | Names only |
| Challenges | Real problems met | Teacher facts, AI wording | Short list |
| Next steps | What follows | Teacher facts, AI wording | Short list |
| Prepared by / Noted by (signatory) | Names and positions | Teacher, left blank | Signature lines empty |
| Date of Filing | Date submitted | Teacher | One line |

## How to fill each part
- **For the Period.** Write "October 1 to 31, 2026". Bad: "this month" (no dates).
- **Summary.** One plain overview. Good: "Taught Grade 5 Science, held three remedial reading sessions, and prepared the Science Fair entries." Bad: "Had a very productive and fruitful month" (no facts).
- **Accomplishment rows.** Itemize by date, one activity per row, with its output. Good: "Checked 38 Quiz 2 papers and returned them with feedback." Bad: "Worked on papers" (no output, no count).
- **Challenges and Next steps.** Only items the teacher gave. Good: "Two class days were lost to a weather suspension." Bad: "Students were lazy" (blame).

## Writing rules
- English or Filipino as the teacher wrote. Past tense for accomplishments, future for next steps.
- Start each row with a verb. One row per activity. No row without a date.
- Facts only. Do not round counts or add praise.
- Avoid: "very successful", "outstanding", "hardworking".

## Free checks code can run
- Every table row has a date inside the period and an output.
- Dates are in order and not in the future.
- Period start is not after period end.
- Counts written in a row match the teacher's number.
- Summary is 3 sentences or fewer.
- Signatory and Date of Filing lines exist and are blank.

## AI must never write
Names of signatories, dates of activities or filing, counts of learners or papers, attendance, amounts spent, outcomes the teacher did not state, causes of problems, blame, and any activity not in the teacher's list. Leave the line blank for the teacher.

## Sample (fictional, for style only)
**ACCOMPLISHMENT REPORT**

For the Period: October 1 to 31, 2026
Name of Personnel: Teacher A
Division: Sample Division
Bureau/Office: Sample Elementary School
Designation: Teacher I

**Summary.** The month covered regular Grade 5 Science and English classes, three remedial reading sessions, and Science Fair preparation.

| Date | Actual Accomplishment/Output | Evidence |
|---|---|---|
| October 1 to 5 | Taught Lesson 4 in Science. Gave Quiz 1 to 38 learners. | Quiz 1 papers |
| October 8 | Held the first remedial reading session. Output: attendance sheet. | Attendance sheet |
| October 12 to 16 | Checked and returned Quiz 1 with written feedback. | Class record |
| October 19 to 23 | Guided learners in making Science Fair posters. Output: 8 posters. | Photos |
| October 26 to 30 | Held the second and third remedial sessions. | Attendance sheets |

**Challenges.** Two class days were lost to a weather suspension.

**Next steps.** Make up the lost lessons in November. Submit the Science Fair entries.

Prepared by: ______________________ Teacher I
Noted by: ______________________ School Head
Date of Filing: ______________
