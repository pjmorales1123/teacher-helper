# Individualized Reading Intervention Plan: how to write it

## What it is and when a teacher uses it
The ARAL reading tutor's weekly plan and progress check for one learner. Each week has a fixed reading target in four literacy domains, a status, and the tutor's notes. The tutor keeps it for the learner and shares progress with the teacher and parents.

## Page setup
A4 landscape (the weekly table is wide), 1-inch margins, Arial 11.

## Parts, in order

| Part | What goes in it | Who supplies it | Length and style |
|---|---|---|---|
| Header: Learner's Name, Grade Level, Tutor's Name, Date | Identity of the plan | Blank lines for the teacher | Never filled by the app |
| Week No. | 1 to the number of weeks (for example 1-10) | Code | Number |
| Reading Target: Phonemic Awareness / Target Letters | Letters or sounds for the week | Code (fixed curriculum row) | Printed as given |
| Reading Target: Phonics and Word Recognition | For example "Reading C-V-C words" | Code (fixed) | Printed as given |
| Reading Target: Fluency | For example "Reading phrases, sentences and short story" | Code (fixed) | Printed as given |
| Reading Target: Reading Comprehension | For example "Answer comprehension questions from the story read" | Code (fixed) | Printed as given |
| Status | Tutor's mark: Achieved, Partly, Not yet | Teacher or tutor | A tick or one word |
| Tutor Notes / Observation | What the tutor saw this week | Tutor; AI may tidy notes the tutor gave | 1-2 short sentences |
| Footer | Prepared by (tutor), Noted by (teacher or school head) | Blank lines | Signatures blank |

## How to fill each part
- **Targets.** They are fixed rows per week from the ARAL tool. The AI does not write or change them. For a week the tool does not cover, leave the row for the tutor.
- **Status.** The tutor's judgment only. If none is given, leave it blank.
- **Tutor notes.** Observable facts. Good: "Read 8 of 10 C-V-C words without help; confused b and d." Bad: "Poor reader" or "Has dyslexia".

## Writing rules
- Strengths first, then the next small step.
- Describe behaviour, never ability labels.
- Short, plain English or Filipino as the tutor writes.

## Free checks code can run
- Week numbers run 1 to N with no gaps.
- Each week has all four targets (from the fixed rows).
- Status is one of the allowed marks or blank.
- Learner name, tutor name and date are blank lines, and the data privacy line is present.

## AI must never write
- The learner's name, grade, reading level, scores or a Phil-IRI classification.
- Any diagnosis (such as dyslexia) or cause.
- Status marks, dates, tutor names or signatures.
- Changes to the weekly targets.
