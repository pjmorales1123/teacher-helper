# LAC Session Report: how to write it

## What it is and when a teacher uses it
A form the LAC facilitator fills in at the end of every LAC session. It records who came, what was used, how the session went and what comes next. One form per session.

## Page setup
A4 portrait, 1-inch margins, Arial 12 (rating table Arial 11). Header block as a two-column table. Fits two pages.

## Parts, in order

| Part | What goes in it | Who supplies it | Length and style |
|---|---|---|---|
| LAC ID | The group's ID | Teacher | Exact value, or blank |
| REGION | Region of the school | Profile/letterhead | Exact value |
| LAC FACILITATOR | Name of the facilitator | Profile (teacher); teacher if someone else | Full name |
| LAC SESSION NO. | Number of the session | Teacher | A number |
| DATE AND TIME OF SESSION | Date, start and end time | Teacher | Full date, times |
| VENUE/PLATFORM OF SESSION | Room or online platform | Teacher | One line |
| Number of members present (attach attendance document) | Count present | Teacher; percent by code | A number |
| Materials and resources | Tick list: Self-Learning Module, Activity sheets, Digital resources, Online resources, Smartphone, PC, LAC session guide, Others (specify) | Teacher | Ticks; Others named |
| Part A: ratings with columns SD, D, N, A, SA, Comments / Remarks; group MEMBER PARTICIPATION (5 statements) and FACILITATION (3 statements) | One tick per statement; a comment if D or SD | Teacher (facilitator) ticks; statements come from the template | One tick; short comment |
| Part B 1. The best part of the session | What went well | Teacher; AI tidies | 1-3 sentences |
| Part B 2. Problems or challenges encountered and how they were resolved | Problems and fixes | Teacher; AI tidies | 1-3 sentences |
| Part B 3. Other topics discussed apart from the recommended topics, if any | Extra topics | Teacher | Phrase or "None" |
| Part B 4. Recommendations/Plans for next LAC session | Next steps | Teacher; AI tidies | 1-3 sentences |

## How to fill each part
- Header lines: copy exactly what the teacher gave. Good: "Session No.: 2; Date: October 15, 2026, 1:00 - 3:00 PM". Bad: "Recently".
- Members present: a number. Good: "7 of 8". Bad: "Most teachers".
- Materials: tick only what the teacher said was used.
- Part A: the facilitator rates, never the AI. Comments are required for D or SD. Leave unticked rows blank and flag them.
- Part B best part: Good: "Members tried the think-pair-share routine and shared how they would use it." Bad: "The session was very successful."
- Part B problems: Good: "Two members arrived late; the facilitator moved the pair work to the second half." Bad: "No problems" when the teacher named one.
- Recommendations: Good: "Next session: bring one sample hands-on activity each." Bad: a topic the teacher never mentioned.

## Writing rules
- Plain, factual English; past tense for what happened, future for plans.
- Facts, not praise. No learner names (RA 10173); do not name members when describing problems.
- Keep every heading and the rating columns as printed.
- Avoid: "very successful", "everyone loved it", "perfect".

## Free checks code can run
- Members present is a number between 0 and the group size; attendance percent is computed by code.
- Session date is inside the school year; times end after they start.
- Every Part A statement has exactly one tick; D or SD rows have a comment.
- All four Part B items are filled ("None" allowed for item 3).
- Facilitator signature line, if present, is blank.

## AI must never write
- Ratings, ticks or counts the teacher did not give.
- Names, IDs, dates, times, venues or session numbers.
- Problems, outcomes or recommendations the teacher did not mention.
- Claims that learner scores rose because of the LAC.

## Open points
- The eight Part A statements are the form's own wording; the app should load them from the bundled template, not from AI.
- The form has no signature line; one is added as an app choice. Owner to confirm.
- Whether attendance percent may be printed on the form is not stated.
