# Project Work Plan and Budget Matrix: how to write it

## What it is and when a teacher uses it
A one-project plan that lists each activity, its output, date, person and cost. A teacher or project lead uses it when a SIP or AIP project needs a budget. The form is attached to the AIP template.

## Page setup
A4 landscape, 1-inch margins, Arial 12 (table cells Arial 11). Four labelled lines on top, then one table. One block per project.

## Parts, in order

| Part | What goes in it | Who supplies it | Length and style |
|---|---|---|---|
| Project Title | Name of the project | Teacher | One line |
| Problem Statement | The problem the project answers | Teacher facts; AI tidies wording | 1-2 sentences, with the teacher's own data |
| Project Objective Statement | What the project will achieve | AI drafts; teacher approves | One SMART sentence |
| Root Cause | Why the problem exists | Teacher facts; AI tidies wording | 1-2 sentences |
| Activity | One action per row | AI drafts; teacher approves | Verb phrase |
| Output | The thing produced by that activity | AI drafts; teacher approves | Countable noun phrase |
| Date of Implementation | When it happens | Teacher | Real dates or month and week |
| Person Responsible | Who does it | Teacher | Role, then name if given |
| Budget | Cost in pesos | Teacher; total by code | Numbers only |
| Budget Source | Where the money comes from | Teacher | Same spelling every row |
| Monitoring date | The date the project will be checked (form note) | Teacher | One date, below the table |
| Total | Sum of the Budget column | Code | Computed |

## How to fill each part
- Project Title: specific. Good: "Project Basa: Grade 3 Reading Recovery". Bad: "Reading Project 1".
- Problem Statement: say who, what, how much, from the teacher's data. Good: "12 of 40 Grade 3 learners read below grade level in the August 2026 reading screening." Bad: "Learners are poor readers" (no data, labels learners).
- Project Objective Statement: Good: "By March 2027, at least 10 of the 12 identified learners read at grade level." Bad: "To improve reading."
- Root Cause: one cause the teacher named, such as "Limited reading materials at home". Do not blame persons.
- Activity: "Hold weekly guided reading sessions". Bad: "Reading".
- Output: "20 session logs; 12 reading records". Bad: "Better readers" (not an output).
- Date of Implementation: Good: "Sep 7, 2026 - Feb 26, 2027, every Monday". Bad: "Soon".
- Person Responsible: "Grade 3 adviser". Bad: a name the teacher never gave.
- Budget and Budget Source: "1,500" and "MOOE". Zero-cost activity: write 0 and "None".

## Writing rules
- Plain English, short phrases in cells; sentences only in the four top lines.
- Each activity has exactly one output.
- Use one spelling per budget source (MOOE, PTA, SEF).
- Avoid: "various", "etc.", "as needed", "improve" without a number.
- Never name learners; use counts.

## Free checks code can run
- All four top lines are filled.
- Every row has Activity, Output, Date, Person Responsible, Budget and Budget Source.
- Budget cells are numbers; a non-zero amount needs a source; Total equals the sum.
- Dates fall inside the school year and the monitoring date is after the first activity.
- At least one activity per project; no duplicate rows.

## AI must never write
- Amounts, funding sources, dates, names of persons, or baselines the teacher did not give.
- The Total (code computes it).
- A monitoring date, an approval, or a signatory.
- Outputs that claim results already happened.

## Sample (fictional, for style only)
**Project Title:** Project Basa: Grade 3 Reading Recovery
**Problem Statement:** 12 of 40 Grade 3 learners read below grade level in the August 2026 reading screening at Sample Elementary School.
**Project Objective Statement:** By March 2027, at least 10 of the 12 identified learners read at grade level.
**Root Cause:** Limited reading materials at home and few reading sessions in class.

| Activity | Output | Date of Implementation | Person Responsible | Budget | Budget Source |
|---|---|---|---|---|---|
| Print graded reading cards | 12 sets of reading cards | Sep 1 - Sep 4, 2026 | Teacher A | 1,500 | MOOE |
| Hold weekly guided reading sessions | 20 session logs | Sep 7, 2026 - Feb 26, 2027, every Monday | Teacher A | 0 | None |
| Give the pre-test and post-test | 12 pre-test and 12 post-test records | Sep 7, 2026; Feb 22, 2027 | Teacher A | 600 | MOOE |
| Set up a classroom reading shelf | 1 shelf with 30 books | Oct 5 - Oct 9, 2026 | Teacher A; PTA officers | 2,400 | PTA |
| **Total** | | | | **4,500** | |

Monitoring date: Dec 11, 2026
Prepared by: Teacher A ______________ Noted by: ______________, School Head

## Open points
- The form has no signature block; "Prepared by" and "Noted by" are an app addition. Owner to confirm.
- Whether one file holds several project blocks or one file per project is not stated on the form.
- Monitoring date is only a note on the form; it is placed below the table here.
