# Quiz and Activity Sheet: how to write it

## What it is and when a teacher uses it
A short quiz or practice sheet on one topic, with Set A and Set B for seatmates and a separate answer key. Used for formative checks, summative quizzes and seatwork.

## Page setup
A4 portrait, 1-inch margins, Arial 12 (14 for Grades 1-3). Key on its own page, marked teacher copy.

## Parts, in order

| Part | What goes in it | Who supplies it | Length and style |
|---|---|---|---|
| Header | "Name ___ Score ___ / Grade level and Section ___ Date ___", title, subject and grade | Blank lines; teacher gives subject and grade | Two lines plus title |
| Directions | One line per part | AI | Plain; tells how to answer |
| Items | Numbered questions; choices A to D for multiple choice | AI; code numbers | One idea each; 60 words or fewer |
| Set A and Set B | Same competencies and item count, different questions and order | AI and code | Equal counts |
| Answer key | Letter or expected answer per item, per set | Code from the stored answer index | Teacher page |

## How to fill each part
- **Items, multiple choice.** A short real-life stem, then four choices of similar length and style. One correct, three believable mistakes. No "all of the above" or "none of the above". Good: "A wet towel dries on a clothesline. Where did the water go?" Bad: "What is the topic of this lesson?"
- **True or false.** One clear claim, wholly true or wholly false. Choices are exactly True and False.
- **Short answer.** The expected answer is a word, number or short phrase. Show it only in the key.
- **Levels.** Mix remember, understand, apply and analyze as the plan says.
- **Set B.** Same skills, new numbers or contexts. Not a copy.

## Writing rules
- Ask about the subject, never about how the topic or competency is worded.
- Grade-level words, Filipino everyday examples (peso, jeepney, local crops); no picture needed.
- The correct choice is never the longest or the shortest on purpose. Code spreads the answer letters.
- Key letters come from the stored answer index, never recomputed by AI.

## Free checks code can run
- Item count equals the request in each set.
- Multiple choice has exactly 4 different non-empty choices.
- True or false choices are exactly True and False.
- No duplicate question inside or across sets.
- Key length equals item count; answer index in range.
- Answer letters not bunched (warn).
- Question length 60 words or fewer.

## AI must never write
- Learner names, scores or grades.
- The answer letter positions (code balances them).
- Questions that refer to a picture or chart that is not there.
- Facts not in the lesson text when one is supplied.

## Sample (fictional, for style only)
**Header:** Name ______ Score ______ / Grade level and Section ______ Date ______
**SCIENCE 5 QUIZ: Parts of a Plant (Set A)**
*Directions: Write the letter of the correct answer.*
1. A gardener waters the soil near a mango tree. Which part takes in the water? A. Leaf B. Root C. Flower D. Fruit
2. Which part of a plant makes food using sunlight? A. Leaf B. Seed C. Root D. Stem
3. True or False: The stem carries water from the roots to the leaves.
4. A bean seed is planted in wet soil. What will grow first? A. Flower B. Fruit C. Root D. Leaf
5. Short answer: Name the part of a plant that becomes a new plant.

**Answer key (teacher copy, Set A):** 1 B; 2 A; 3 True; 4 C; 5 Seed.

## Open points
- Seat-work activity sheets (no key, tasks instead of items) share this header; a task-style layout is not specified yet.
- Long paper vs A4 is a school choice; default is A4.
