# Periodical test paper with Table of Specifications: how to write it

## What it is and when a teacher uses it
A Table of Specifications (TOS) plans a test: which competencies, how many items, at which thinking level. The test paper follows the TOS item by item. A teacher makes both before a periodical or summative test, files the TOS with the principal, and keeps a separate answer key.

## Page setup
| Setting | Memo default (long paper) | School option |
|---|---|---|
| Paper | Long bond, 8.5 x 13 inch | A4 |
| Orientation | TOS: landscape. Test paper: portrait | same |
| Margins | 1 inch all sides | same |
| Font | Arial 12 (app house style); a grade font from the school format overrides it | same |
| Key | Own page, marked "TEACHER COPY" | same |

Long paper is for tests only. Other tools stay A4.

## Parts, in order
| Part | What goes in it | Who supplies it | Length and style |
|---|---|---|---|
| 1. TOS title block | School, "TABLE OF SPECIFICATIONS", test name, subject, grade, school year | profile, teacher | 4 short lines, centred |
| 2. TOS table | Competency, days, items, %, placement per level | competencies: picker. Numbers: code | one row per competency, totals row |
| 3. Signatory blanks | Prepared by, Checked by, Noted by | blank for the teacher | 3 lines, no names |
| 4. Test header | Name, Score, Grade level and Section, Date | code (blanks) | 2 lines |
| 5. Title | "FIRST PERIODICAL TEST", subject, grade | teacher, profile | centred, bold |
| 6. Directions | One per part | AI | 1 to 2 sentences |
| 7. Items | Numbered, stem, choices A to D | AI | one idea each |
| 8. Answer key | Number and letter, on a new page | code from AI items | compact grid |

## How to fill each part
### TOS title block
Write: school name, test name, subject, grade, school year. Good: "FIRST PERIODICAL TEST, SCIENCE 5, SY 2026-2027". Bad: "Test for the lessons we did" (not a name, not a year).

### TOS table
Columns, in this order: Learning Competencies | No. of Teaching/Discussion Days | No. of Items | % of Items | Item Specification (placement) under R, U, Ap, An, E, C. Each level cell shows the count and, in brackets, the item numbers. The last row totals days, items, % and each level.
- Competency text is copied from the picker, word for word.
- Items per competency follow days taught. Code rounds by largest remainder so the sum equals the test length.
- Thinking split default (memo): Remembering 5, Understanding 25, Applying 30, Analyzing 25, Evaluating 10, Creating 5 percent. The app also offers Balanced, More recall, More higher-order.
- Small tests cannot match the split exactly. Code rounds, and the totals row shows the real numbers.

### Signatory blanks
Three labelled lines: "Prepared by: ______", "Checked by: ______", "Noted by: ______". Good: blank lines with the role under each. Bad: a filled-in principal name.

### Test header
Line 1: "Name: ______  Score: ______". Line 2: "Grade level and Section: ______  Date: ______". Code prints it. The answer-line-before-the-number style ("___ 1.") is a school option.

### Title, subject and grade
Centred, capitals: "FIRST PERIODICAL TEST". Next line: "Science 5" or "Araling Panlipunan 6". The term name follows the school's wording (quarter or term).

### Directions
Pattern: "Read each question carefully. Write the letter of the best answer on the line before the number." Bad: "Answer the following." It does not say how to answer.

### Items
Numbered 1 to N across the whole paper. Stem first, then A to D on separate lines. Multiple choice is the default for periodical tests (memo). Other types sit in their own part with their own directions.

### Answer key
New page, "ANSWER KEY (Teacher Copy)", then "1. B  2. D ...". Add the TOS level beside each number only if the teacher asks.

## Item and criterion writing rules
- Stem is a clear question or a short complete statement, 60 words or fewer.
- Exactly four choices, similar in length and form.
- Exactly one correct answer.
- Wrong choices are believable mistakes a learner of this grade would make.
- Never use "all of the above" or "none of the above".
- Ask about the subject matter. Never ask how the topic or competency is worded.
- One idea per item. No double negatives.
- Words the grade can read. English or Filipino, not mixed in one item.
- Use Filipino settings: peso, jeepney, sari-sari store, local crops, typhoon.
- Higher levels (Applying to Creating) use a short situation, not a longer stem of facts.
- Items follow the TOS: each item carries its competency number and level, and counts per cell match the plan.
- Do not point to a picture or chart that is not printed.

## Free checks code can run
- TOS: row items add to total; days add; % add to 100 (largest remainder); each level column adds to its total.
- Each cell's item count equals the number of AI items tagged with that competency and level.
- Item count equals the requested test length; numbers run 1 to N with no gaps.
- Every item has exactly 4 distinct choices; one answer index in range.
- Key length equals item count; answer letters spread over A to D (code rebalances letters without changing wording; no letter above about 40 percent).
- No duplicate stems; no choice repeated inside an item.
- No "all of the above" or "none of the above"; stem length at most 60 words.
- Competency text equals the picker text.
- Header, title and the three signatory lines are present.
- Items the model could not source from the lesson are marked "unverified" for teacher review.

## AI must never write
- Learner names, school names, teacher names, scores or grades.
- Any TOS number: days, items, percent, placement, totals.
- Signatories (Prepared, Checked, Noted by).
- Competency text or codes.
- The answer key letters (code derives them).

School: [School name], SY 2026-2027. Prepared by: [Teacher name].

**TABLE OF SPECIFICATIONS, FIRST PERIODICAL TEST, SCIENCE 5**

| Learning Competencies | Days | Items | % | R | U | Ap | An | E | C |
|---|---|---|---|---|---|---|---|---|---|
| 1. Parts and functions of the digestive system | 3 | 4 | 40 | 1 (1) | 1 (2) | 1 (3) | 1 (4) | | |
| 2. Healthy eating habits for digestion | 2 | 3 | 30 | | 1 (5) | 1 (6) | 1 (7) | | |
| 3. Caring for the digestive system | 2 | 3 | 30 | | | 1 (8) | | 1 (9) | 1 (10) |
| **Total** | **7** | **10** | **100** | **1** | **2** | **3** | **2** | **1** | **1** |

Levels: 10/20/30/20/10/10 percent. The memo split is 5/25/30/25/10/5; at 10 items code rounds to whole items.

Prepared by: ________  Checked by: ________  Noted by: ________

**Test paper**

Name: ________  Score: ________ / 10
Grade level and Section: ________  Date: ________

FIRST PERIODICAL TEST
Science 5

Directions: Read each question carefully. Write the letter of the best answer on the line before the number.

___ 1. Which organ takes most digested nutrients into the blood?
A. Stomach  B. Small intestine  C. Large intestine  D. Esophagus

___ 2. Why does chewing help digestion?
A. It makes the food taste sweeter.
B. It removes the water from the food.
C. It changes the food directly into blood.
D. It breaks the food into small pieces for digestive juices.

___ 3. Lito swallows a piece of pandesal. Which shows the path it takes?
A. mouth, esophagus, stomach, small intestine
B. mouth, stomach, esophagus, small intestine
C. mouth, small intestine, stomach, esophagus
D. mouth, esophagus, small intestine, stomach

___ 4. A learner's large intestine stops working well. What would most likely happen?
A. The mouth could not make saliva.
B. The stomach could not churn food.
C. Too much water would leave the body with waste.
D. The esophagus would stop moving food.

___ 5. Why is eating kangkong and malunggay good for digestion?
A. Their fiber helps waste move through the intestines.
B. Their fiber is changed into blood in the stomach.
C. Their fiber gives the body most of its energy.
D. Their fiber stops the mouth from making saliva.

___ 6. Ana needs a snack before sports. Which lunch box is best for her digestion?
A. Fried chicken skin and a soft drink
B. Candy and chips
C. A boiled banana, a boiled egg and water
D. Instant noodles and soda

___ 7. Tomas often has a stomachache after eating very fast. Which explanation fits best?
A. The food went straight to his lungs.
B. His stomach made too much blood.
C. Saliva turned all the food to water.
D. The food was not chewed well, so his stomach and intestines worked harder.

___ 8. Which daily habit helps prevent constipation?
A. Skipping breakfast
B. Drinking water and eating fruits and vegetables
C. Eating only rice
D. Holding back the urge to use the toilet

___ 9. Kyle says to wash hands before eating because germs can reach the stomach. Dina says handwashing is not needed because stomach acid kills all germs. Who is correct?
A. Kyle, because germs can reach the digestive system and cause illness.
B. Dina, because stomach acid kills all germs.
C. Both, because germs cannot cause sickness.
D. Neither, because food is always clean.

___ 10. Which plan would best keep a class's digestive systems healthy for one week?
A. Eat only sweets at every meal.
B. Skip meals so the stomach can rest.
C. Drink soft drinks instead of water.
D. Make a daily chart of fruit and vegetable servings, water and handwashing.

## Open points
- Memo split 5/25/30/25/10/5 is not in code yet; code offers Balanced (30/20/20/15/10/5), More recall, More higher-order.
- The built TOS table has no "% of Items" column and calls days "Days"; the memo wants both. Code change needed.
- Code gives every competency equal days (no days field on the form); the memo weights by days taught.
- Quarter vs term wording depends on DO 015 s.2026 (unconfirmed).
- Is long paper the default for every school or only Muntinlupa?
- "Mark unverified items" has no flag in the item data yet.
