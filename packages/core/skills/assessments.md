# Table of Specifications (TOS)
- Columns usually: learning competency (verbatim, with code if used), number of days/hours taught, percentage,
  number of items, item placement per cognitive level, total.
- Percentage = days for the competency / total days x 100. Items = percentage x total items, rounded so the column
  sums exactly to the total (adjust the largest share).
- Cognitive levels: keep the taxonomy the template uses. Most use revised Bloom's (Remembering, Understanding,
  Applying, Analyzing, Evaluating, Creating); some SY 2026-2027 division TOS files use SOLO (Uni-structural,
  Multi-structural, Relational, Extended abstract). The level split also comes from the template or division memo
  (examples seen: 60/30/10 easy/average/difficult; 5/25/30/25/10/5 across the six Bloom levels in a Muntinlupa
  memo). If none is given, ask or state the split you used.
- Item placement lists the actual item numbers, and every item number appears once.
- Under DO 8, s. 2015 the knowledge/process/understanding levels were also used; keep whatever the template uses.

# Writing test items
- One clearly correct answer; distractors plausible and based on common misconceptions.
- Options similar in length and grammar, in logical order (numbers ascending). Avoid "all/none of the above".
- Stems are complete questions; avoid negatives, or put NOT in bold caps.
- No clues from one item to another. Items match the competency and the level in the TOS.
- Use Filipino names, places and contexts. Keep reading level at the grade.
- Always provide an answer key (separate section or page) and, for open items, a rubric.
- Test directions: what to do, how to answer, time if timed. Number items continuously.

# Rubrics
- Criteria in rows, performance levels in columns (e.g. 4 Excellent, 3 Proficient, 2 Developing, 1 Beginning),
  each cell an observable description; weights or points per criterion and the total.

# Item analysis
- Difficulty index = number who got it right / number of examinees; discrimination = upper group correct minus
  lower group correct, divided by group size. Interpret, do not invent counts.

# How to work on a test or TOS
1. Find the competencies covered and the days spent on each (from the TOS, the budget of work or the teacher).
2. Build or check the TOS first; then write items to fill exactly its cells (count per competency and level).
3. Write items, then the answer key; check that every key is correct and options are not repeated.
4. Check: item count equals the TOS total, numbering is continuous, each item has 1 key, directions are present.
