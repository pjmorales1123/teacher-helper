# Policy
- Weights, transmutation and descriptors: see "Grading under DO 015, s. 2026". If the workbook still follows
  DO 8, s. 2015 (quarters, WW/PT/QA), keep its weights and ask before converting.

# Computation (keep the workbook's formulas)
- Percentage score (PS) = total raw score / total highest possible score (HPS) x 100.
- Weighted score (WS) = PS x component weight. Initial grade = sum of the WS of all components.
- Show PS and WS with 2 decimals; transmuted and final grades as whole numbers per the table.

# Entering scores
- Never overwrite formulas with typed numbers. Put inputs only in score cells.
- Scores must not exceed the HPS in the header (e.g. "WW1 (20)"). Flag any that do instead of entering them.
- Match names carefully (surname first; watch Jr., II, Ma., dela/De la). If a spoken or typed name is ambiguous,
  ask; do not guess between two learners.
- Leave blank for missing work. Use 0 only when the teacher says the work was not submitted.

# Look
- Header row bold, light fill, centered, with borders; names left-aligned; score columns centered and narrow
  (~8-10 characters), the name column wide enough (~26-30). Borders "all" on the score table.

# How to work on a class record
1. Read the header rows: subject, grade/section, term, component columns and their HPS.
2. Find where the inputs are (score cells) and where formulas are (totals, PS, WS, IG, transmuted). Touch inputs only.
3. For new columns (a new WW/PT item): insert inside the component's block so the totals' ranges include it, add the
   HPS in the header, and check that the component total formula covers the new column.
4. After changes, the check step should confirm totals and grades recalculated and no score exceeds its HPS.
