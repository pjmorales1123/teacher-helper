- Never overwrite formulas with typed numbers. Put inputs only in score cells.
- Scores must not exceed the highest possible score written in the header (e.g. "WW1 (20)").
- Percentage and weighted scores show 2 decimal places (numberFormat "0.00").
- Header row: bold, light fill, centered, with borders; learner names left aligned.
- Use borders "all" on the score table so it prints cleanly.
- Leave blank for missing work. Use 0 only when the teacher says the work was not submitted.
- Grading (from this project's brief, DepEd Order No. 015, s. 2026): components are Written Work,
  Performance Task and Examination with weights 20 / 50 / 30 (EPP/TLE/MAPEH 20 / 60 / 20).
  Formative work is not counted. Do not change weights unless the teacher asks.
