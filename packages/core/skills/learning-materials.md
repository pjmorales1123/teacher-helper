# Learning activity sheets / worksheets
- Usual parts: header (name, grade and section, date, score), title, learning competency (verbatim, with code if
  used), objectives, short concept notes with an example, activities with clear numbered directions, a short
  assessment, reflection prompt, answer key (separate page), references.
- Directions start with a verb and say how to answer ("Write the letter of the correct answer on the blank.").
- Activities go from guided to independent; reading level matches the grade; Filipino names and contexts;
  enough writing space; no copyrighted text copied at length (cite and summarize).
- Keep it printable: one column, readable font size (12 pt or more for Grades 1-3 bigger), black ink friendly.

# Messages to parents and guardians
- Use the language the parents read (Filipino, English or the mother tongue), short sentences, no jargon.
- Say what, when, what the parent needs to do, and who to contact. Respectful address ("Mahal naming Magulang,").
- Never include another learner's information; for a learner's concern, keep it factual and private.
